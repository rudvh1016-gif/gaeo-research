## 3. 소유자 할 일(계정이 필요해 작업자가 대신하지 않음)
1. **Google Search Console** → 속성 `gaeoteam.com` → Sitemaps 에 `https://gaeoteam.com/sitemap.xml` 제출 → URL 검사로 `https://gaeoteam.com/guide/`, `https://gaeoteam.com/company/005930/`, `https://gaeoteam.com/snap/study/31.html` 색인 요청.
2. **네이버 서치어드바이저** → 사이트 목록에서 `https://gaeoteam.com` 소유 확인이 살아 있는지 본다(풀렸으면 「HTML 태그」 방식의 값을 알려 주면 사이트 머리말에 넣는다) → 요청 → 사이트맵 제출 `https://gaeoteam.com/sitemap.xml` · RSS 제출 `https://gaeoteam.com/rss.xml` → 웹 페이지 수집 요청(위 3개 주소).
3. **Bing 웹마스터 도구** → Search Console 에서 가져오기 → sitemap 확인(IndexNow 는 자동).
4. **다음 웹마스터 도구** → 확인 줄을 되돌렸으니 사이트 확인 상태를 다시 본다.
5. 2주 뒤 Search Console 「실적」(노출·클릭)과 서치어드바이저 「수집 현황」을 확인해 알려 주면 다음 순서를 정한다.
